# Results

Output files generated by the analysis pipeline. All files are saved using `sciris.saveobj()`.

## Calibration outputs (from `run_calibrations.py`)

| File | Description |
|------|-------------|
| `zimbabwe_calib.obj` | Full calibration object (shrunk) |
| `zimbabwe_pars.df` | Top calibrated parameter sets (DataFrame) |

## Multi-sim outputs (from `run_msim.py`)

| File | Description |
|------|-------------|
| `zimbabwe_calib_stats_{scenario}.df` | Percentile statistics by year (~100 columns) |

## Scenario outputs (from `run_scenarios.py`)

| File | Description |
|------|-------------|
| `scenario_{name}.df` | Long-format results per scenario (year x metric x par_idx) |
| `all_scenarios.df` | Combined results across all scenarios |
